HTML
* stands for Hyper text markup language
* used to create structure of web page
* Also known as skeleton of web page
* A single HTMl doc is known as web page.
* Invented by "Tim Berners Lee" in 1991 . at wwwConsortium(cern).
*Hyper text: it refers to an text on web page , which is linked internally together where another web page.
* Markup language: it is an high level language , used to create structure of web page using tags.
* Current vesion of html is html5.
* Currently HTML language is managing by WHATWG(Web Hypertext Application Technology Working Group).


* Features of HTML
-> It is widely used markup language on web development to develop web page.
-> It is Easy to Learn.
-> It is light weighted and fast to load.
-> Supports to stop large file and it is defauletly enabled browser engine;
-> MAjor Browser supports html.
-> It is case insensitive.

  Tag : 
  => Tags are the predefined keywords written inside angular bracket(<>)
  => Tags acts like container to hold content ,and tells the browser how the display the content the user.
  => Example : <html>, <img> and <vedeo>
  => Types :
  1. Paired tag:
            ** The tags which are having both opening and closing tags.
            ** Also Known as double tag
            ** Paired tags hold the content inside it and returns the content.
            ** Syntax:
                 <open> text content </close>
            ** Example : <title></title>, <p> </p>, <vedeo> </vedeo>

   2. Unpaired tag:
         ** The tag which closes by itself /the tags which are having only opening tag are known as unpaired tag.
         ** Also Known as single tag, void elements (returns nothing).
         ** syntax :
            <open attributes> 
         ** Example: <link>, <meta>, <img>, <hr> and <br>                                    

     => Heading tags
       1. <h1></h1>  -> Main heading tags and should be used only one time in one page
       2. <h2> </h2>
       3. <h3> </h3>
       4. <h4> </h4>
       5. <h5> </h5>
       6. <h6> </h6>

  => Semantic element  :
  * Elements those describes the content meaning and purpose.
  * Used for readability, SEO optimisation.
  * Example : <div> -> <nav> to describe navigation content.
                       <aside> to create side menu.
                       <main>/ <article> to describe main content in the web page
                       <footer> to describe footer content.

                    <b> -> <strong>
                    <u> -> <ins>
                    <i> -> <em>      

    => Attributes :
       * Attributes are part of markup language , used to add behavior and style to an html element.
       * Makes tags as fully functional.
       * common attributes - style , id, class, name, type, src, href, controls, checked, etc....

       * Syntax :
       <open attr_name = "value"> Content </close>  

  ** Body tag attributes:
   1> bgcolor: define background color to web page
   2> background : adds an image in background
   3> align :  align the items in the left right top buttom
   4> text  :    define color of text content

IFRAME 
  -> stands for inline frame.
  -> <iframe> is used to create nested web page.
  -> it is paired, inline.
  -> it is used to embed external web pages into our web page.
  *Syntax:-
      <iframe src="" frameborder="">
        file format not supported by browser

      -> Attrubutes :
         src: source ->name/path/url
         frameborder: -> define border around iframe
      -> Ex:
        Payment intigration ,youtube videos, google map.

HYPER LINKS
-> IT IS AN METHOD TO CREATE HYPERTEXT.
-> <a> (Anchor) tag is used to create Hyper text
-> Paired tag and inline element
-> syntax
   <a href='' target=''>Content </a>

-> Attribute:
   1.href : Hyper Reference -> Name/path/url
   2.target: New page location decides
   3.download: used to download files from server
